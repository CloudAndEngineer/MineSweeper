# MineSweeper Project

## 1. Synopsis

* It's my first toy project using `Spring Boot 4.1.1` and `Vue 3.4`.
* Cuz I'm a junior student majoring Computer Engineering and I found my GitHub repository just left alone, I decided to make a project first, though the scale isn't huge.
* The project is assisted by Gemini - actually it took over the role as a consultant and I designed backend code except controller layer by myself to totally understand layered architecture.

## 2. How to Download and Run

1. Download the whole package.
2. Install `Java 25` and `Node.js >=24.21.0` if you don't have them.
3. Open Terminal and input `cd <Project Root Directory Path>/frontend`.
4. Input `npm install` then packages mentioned in `frontend/package.json` will be installed.
5. Run `MineSweeperApplication`.
6. Input `npm run dev`.
7. Open a browser and input `localhost:5173`.

## 3. How to Play

* Connect to `localhost:5173` first after loading backend server and `node.js`.
* You can see a dropdown menu and choose difficulties(easy, medium, hard, custom).
* Click any tile AFTER clicking start(게임 시작) button.
* The rule is as the same as the standard Minesweeper.
